# VM Scenarios

Status markers:

- `manual`: requires a human setup or observation step.
- `requires-approved-installer`: requires an approved Grabber MSI copied manually into `.\assets\`.
- `requires-hidden-wmi-install`: requires an approved hidden WMI installation state.
- `requires-policy-managed-defender`: requires Defender policy management in the VM/lab.
- `requires-third-party-av`: requires approved third-party AV in the VM/lab.
